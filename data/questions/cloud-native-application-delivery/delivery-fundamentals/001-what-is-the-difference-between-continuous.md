# Question

What is the difference between Continuous Integration (CI) and Continuous Delivery/Deployment (CD)?

## Options

- [x] CI is about frequently merging and testing code changes; CD is about reliably getting the tested build to staging/production, automatically or with one click
- [ ] CI and CD are two names for the exact same activity
- [ ] CI only applies to databases, CD only applies to frontends
- [ ] CI happens after release, CD happens before code is written

## Explanation

CI focuses on integrating code frequently and validating it with automated builds and tests; CD extends the pipeline to package, promote, and release that validated build, either continuously deploying it automatically or continuously delivering it ready for a manual release step.

## Explicação para criança

CI é como juntar e testar os pedaços de um quebra-cabeça sempre que alguém adiciona uma peça nova; CD é levar o quebra-cabeça já pronto e testado até a vitrine para todo mundo ver.
