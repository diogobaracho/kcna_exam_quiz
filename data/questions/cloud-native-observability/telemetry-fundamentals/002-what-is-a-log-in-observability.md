# Question

What is a log, in observability terms?

## Options

- [x] A timestamped, immutable record of a discrete event that happened in a system
- [ ] A continuously sampled numeric value like CPU percentage
- [ ] A record of a request's path across multiple services
- [ ] A configuration file describing desired state

## Explanation

Logs capture specific events (an error, a request received, a state change) with context and a timestamp; they are best for understanding exactly what happened at a particular moment, though they can be voluminous and unstructured.

## Explicação para criança

É como um diário de bordo: cada linha registra algo que aconteceu num momento específico, com hora marcada.
