# Question

What problem do distributed traces help diagnose that logs and metrics alone often cannot?

## Options

- [x] Understanding how a single request flows across multiple microservices and where time is spent along that path
- [ ] Measuring total disk usage on a node
- [ ] Counting how many Pods exist in a namespace
- [ ] Storing configuration data securely

## Explanation

A trace links together the spans generated by each service a request touches, letting engineers see the full call chain and pinpoint exactly which downstream service or hop introduced latency or an error, something hard to reconstruct from separate logs.

## Explicação para criança

É como seguir o rastro de uma encomenda por vários depósitos diferentes até chegar à sua casa, para descobrir exatamente onde ela ficou parada mais tempo.
