# Question

How does a Service Level Objective (SLO) relate to a Service Level Agreement (SLA)?

## Options

- [x] The SLO is the internal reliability target a team aims for; the SLA is often a stricter, external contractual commitment (sometimes with financial penalties) based on similar indicators
- [ ] They are exactly the same document with a different name
- [ ] An SLA is measured, while an SLO is a legal document
- [ ] SLOs only apply to networking, SLAs only apply to storage

## Explanation

Teams typically set an SLO (e.g. 99.9% availability) as an internal engineering target, often kept a bit stricter than any SLA promised externally to customers, leaving margin before contractual penalties would be triggered.

## Explicação para criança

É como a meta que você mesmo se propõe bater em casa (SLO), sendo um pouco mais rígida do que a promessa formal que você faz para um cliente (SLA), para ter uma margem de segurança.
