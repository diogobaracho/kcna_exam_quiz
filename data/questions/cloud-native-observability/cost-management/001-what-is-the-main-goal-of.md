# Question

What is the main goal of FinOps practices applied to a Kubernetes cluster?

## Options

- [x] Giving engineering teams visibility into what their workloads cost, so spending decisions can be made collaboratively and with data
- [ ] Eliminating the cloud bill entirely
- [ ] Replacing autoscaling with fixed capacity
- [ ] Moving all workloads off Kubernetes

## Explanation

FinOps for Kubernetes focuses on attributing shared cluster costs (compute, storage, network) back to individual teams, namespaces, or workloads, so engineers can see the cost impact of their decisions and optimize accordingly.

## Explicação para criança

É como mostrar para cada morador do prédio exatamente quanto da conta de luz ele gastou, para que cada um possa decidir economizar de forma consciente.
