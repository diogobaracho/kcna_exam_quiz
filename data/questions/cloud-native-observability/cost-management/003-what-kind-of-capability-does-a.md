# Question

What kind of capability does a tool like Kubecost provide?

## Options

- [x] Cost visibility and allocation for Kubernetes resources, broken down by namespace, deployment, label, or team
- [ ] It replaces the Kubernetes scheduler with a cost-aware one
- [ ] It is a container registry with billing features
- [ ] It is a CNI plugin for cost-aware networking

## Explanation

Kubecost-style tools combine cluster resource usage with cloud pricing data to estimate and break down the cost of running specific workloads, namespaces, or teams, supporting the visibility that FinOps practices rely on.

## Explicação para criança

É como um extrato detalhado que mostra quanto cada apartamento (namespace ou time) realmente contribuiu para a conta total do prédio.
