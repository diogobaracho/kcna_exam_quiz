# Question

What is Grafana commonly used for in a cloud native observability stack?

## Options

- [x] Building dashboards to visualize metrics (often from Prometheus and other data sources)
- [ ] Scraping metrics from application endpoints
- [ ] Storing container images
- [ ] Managing Kubernetes RBAC policies

## Explanation

Grafana is a visualization and dashboarding tool that connects to many data sources (Prometheus, Loki, Elasticsearch, and more), letting teams build graphs, tables, and alerts on top of stored telemetry data.
