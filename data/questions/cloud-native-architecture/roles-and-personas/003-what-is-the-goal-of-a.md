# Question

What is the goal of a platform engineering team in a cloud native organization?

## Options

- [x] Building an internal developer platform (self-service tools, golden paths) so application teams can ship software without becoming infrastructure experts
- [ ] Writing all application business logic for every team
- [ ] Replacing the need for Kubernetes
- [ ] Manually approving every single deployment

## Explanation

Platform engineering teams build reusable, self-service infrastructure and tooling (CI/CD templates, provisioning APIs, paved paths) that reduce cognitive load on application developers, letting them focus on business logic rather than deep infrastructure expertise.

## Explicação para criança

É como montar um parquinho pronto com brinquedos seguros para as outras crianças (times de desenvolvimento) brincarem sem precisar construir cada brinquedo do zero.
