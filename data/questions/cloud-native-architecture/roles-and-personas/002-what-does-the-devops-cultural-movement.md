# Question

What does the DevOps cultural movement primarily emphasize?

## Options

- [x] Breaking down silos between development and operations teams through collaboration, automation, and shared responsibility
- [ ] Hiring a single dedicated 'DevOps' department that owns all deployments
- [ ] Eliminating the operations role entirely
- [ ] Replacing all manual testing with a single tool

## Explanation

DevOps is a set of practices and a culture aiming to shorten the feedback loop between writing code and running it in production, through shared ownership, automation (CI/CD), and closer collaboration between developers and operators.

## Explicação para criança

É como fazer os cozinheiros e os garçons trabalharem juntos e se ajudarem, em vez de cada grupo ficar isolado e só jogar a responsabilidade para o outro lado.
