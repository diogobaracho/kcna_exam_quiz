# Question

What is the core idea behind the Site Reliability Engineering (SRE) role, as popularized by Google?

## Options

- [x] Applying software engineering practices to operations problems, often guided by measurable reliability targets like SLOs
- [ ] SRE is another name for a help-desk technician
- [ ] SRE only writes documentation and never touches production
- [ ] SRE replaces the need for developers entirely

## Explanation

SREs treat operations as a software problem: they automate toil, build monitoring and alerting, and use error budgets derived from Service Level Objectives to balance reliability work against feature velocity.

## Explicação para criança

É como um engenheiro que cuida da casa inteira funcionando bem, usando ferramentas e números (metas de qualidade) para decidir quando consertar algo e quando construir coisas novas.
