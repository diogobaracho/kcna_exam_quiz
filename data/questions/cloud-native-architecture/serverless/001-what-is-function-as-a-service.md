# Question

What is Function-as-a-Service (FaaS)?

## Options

- [x] A model where you deploy small, single-purpose functions that a platform runs on demand in response to events, without managing servers
- [ ] A model where you rent whole virtual machines by the hour
- [ ] A container orchestration tool
- [ ] A type of Kubernetes Service

## Explanation

In FaaS, developers upload individual functions (not whole applications); the platform handles provisioning, scaling, and invocation in response to triggers like HTTP requests or queue messages, abstracting away server management.

## Explicação para criança

É como pedir para alguém fazer só uma tarefinha específica quando você chama, em vez de contratar uma pessoa para ficar o dia inteiro esperando ter trabalho.
