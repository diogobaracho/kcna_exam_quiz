# Question

What is the Cloud Native Computing Foundation (CNCF)?

## Options

- [x] A Linux Foundation project that hosts and stewards open source cloud native projects like Kubernetes, Prometheus, and Envoy
- [ ] A for-profit company that sells Kubernetes licenses
- [ ] A certification body unrelated to open source software
- [ ] A hardware vendor that manufactures servers

## Explanation

The CNCF is a vendor-neutral home under the Linux Foundation for cloud native open source projects; it provides governance structure, funding, infrastructure, and neutral trademark ownership so projects can grow independently of any single company.

## Explicação para criança

É como uma casa comum onde vários projetos de código aberto moram juntos, com regras neutras que não favorecem nenhuma empresa específica.
