# Question

What is the role of the CNCF's Technical Oversight Committee (TOC)?

## Options

- [x] It provides technical governance for the CNCF, including project maturity level decisions (sandbox, incubating, graduated)
- [ ] It writes all the code for every hosted project
- [ ] It sells enterprise support contracts
- [ ] It manages CNCF's marketing budget only

## Explanation

The TOC is an elected body responsible for technical direction and governance of the CNCF's project portfolio, including defining and approving a project's progression between maturity levels.

## Explicação para criança

É como um conselho de professores que decide se um projeto de aluno já está pronto para passar de série (de sandbox para incubado, e depois para formado).
