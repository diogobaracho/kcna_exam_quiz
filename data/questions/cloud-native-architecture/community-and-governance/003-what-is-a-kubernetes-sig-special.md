# Question

What is a Kubernetes SIG (Special Interest Group)?

## Options

- [x] A community group focused on a specific area of the project (like SIG-Networking or SIG-Storage) that drives design and development in that area
- [ ] A paid support tier offered by a cloud vendor
- [ ] A single company's internal team with no public visibility
- [ ] A certification exam track

## Explanation

SIGs organize the huge Kubernetes contributor community around specific technical domains, each with its own regular meetings, leads, and decision-making process, feeding into the overall project through Kubernetes Enhancement Proposals (KEPs) and code review.

## Explicação para criança

É como clubes dentro de uma escola grande, cada um focado num assunto (esportes, teatro, robótica), onde as pessoas interessadas naquele tema se juntam para trabalhar nele.
