# Question

What is a Kubernetes Enhancement Proposal (KEP)?

## Options

- [x] A design document process used to propose, discuss, and track significant changes or new features in Kubernetes
- [ ] A paid feature only available to CNCF member companies
- [ ] A bug report template used only by end users
- [ ] A benchmark suite used to certify Kubernetes distributions

## Explanation

KEPs are the standard way substantial changes to Kubernetes are proposed: they document motivation, design, and graduation criteria (alpha/beta/stable), and are reviewed by the relevant SIG before implementation begins, giving the community visibility into upcoming changes.

## Explicação para criança

É como um projeto escrito que você entrega antes de começar a construir algo grande na escola, explicando o que quer fazer e por quê, para os professores (a comunidade) darem sua opinião antes.
