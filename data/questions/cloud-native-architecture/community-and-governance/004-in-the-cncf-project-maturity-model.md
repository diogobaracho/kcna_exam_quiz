# Question

In the CNCF project maturity model, what does 'graduated' generally indicate about a project, compared to 'sandbox'?

## Options

- [x] The project has demonstrated broad adoption, a healthy governance process, and passed a thorough due-diligence review, unlike an early-stage sandbox project
- [ ] Graduated projects are always older than sandbox projects, with no other requirements
- [ ] Sandbox projects have more contributors than graduated ones
- [ ] Graduated status is granted automatically after one year

## Explanation

Sandbox is the entry level for early-stage, experimental projects; incubating requires demonstrated adoption and a documented process; graduated is the highest level, requiring committer diversity, a documented governance process, and passing a security audit, signaling production readiness at scale.

## Explicação para criança

É como as fases de uma escola: sandbox é o jardim de infância (aprendendo o básico), incubating é o ensino fundamental (crescendo), e graduated é a formatura (já provou que está pronto).
