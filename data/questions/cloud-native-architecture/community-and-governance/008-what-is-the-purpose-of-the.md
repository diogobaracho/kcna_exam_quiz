# Question

What is the purpose of the CNCF Cloud Native Landscape?

## Options

- [x] A curated map of cloud native projects and products, organized by category, to help people navigate the ecosystem
- [ ] A geographic map of where CNCF member companies' offices are located
- [ ] A list of banned technologies within cloud native projects
- [ ] The official Kubernetes architecture diagram

## Explanation

The Cloud Native Landscape visually organizes hundreds of tools and platforms (both CNCF-hosted and independent) into categories like orchestration, observability, and security, helping newcomers and practitioners understand what options exist for a given problem.

## Explicação para criança

É como um mapa de shopping gigante mostrando onde fica cada tipo de loja (roupas, comida, eletrônicos), só que para ferramentas de tecnologia cloud native.
