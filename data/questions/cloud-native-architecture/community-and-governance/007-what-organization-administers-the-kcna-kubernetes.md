# Question

What organization administers the KCNA (Kubernetes and Cloud Native Associate) certification exam covered by this quiz app?

## Options

- [x] The Linux Foundation, in partnership with the CNCF
- [ ] A private company unrelated to Kubernetes
- [ ] Only Google Cloud
- [ ] The Apache Software Foundation

## Explanation

The Linux Foundation, working with the CNCF, administers KCNA and related certifications (like CKA and CKAD), aligning them with the vendor-neutral, community-driven nature of the underlying projects.

## Explicação para criança

É como uma escola reconhecida oficialmente que emite o diploma: a Linux Foundation, junto com a CNCF, é quem organiza e valida essa prova.
