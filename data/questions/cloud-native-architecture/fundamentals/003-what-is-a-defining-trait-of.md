# Question

What is a defining trait of a microservices architecture, compared to a monolith?

## Options

- [x] The application is split into small, independently deployable services, each owning a specific piece of business capability
- [ ] All functionality is compiled into a single deployable binary
- [ ] Microservices must all be written in the same programming language
- [ ] Microservices cannot communicate with each other over a network

## Explanation

Instead of one large codebase deployed as a unit, microservices decompose an application into independently deployable, loosely coupled services that communicate over the network (often HTTP or messaging), enabling teams to build, scale, and release them separately.

## Explicação para criança

É como dividir uma grande cozinha em várias barraquinhas especializadas (uma só de sobremesa, outra só de bebidas) em vez de uma cozinha gigante que faz tudo junto.
