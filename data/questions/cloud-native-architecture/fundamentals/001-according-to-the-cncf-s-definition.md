# Question

According to the CNCF's definition, which characteristics describe 'cloud native' technologies?

## Options

- [x] They use containers, microservices, and declarative APIs to build scalable, resilient, and manageable applications
- [ ] They only run on a single vendor's public cloud
- [ ] They require rewriting every application in Go
- [ ] They avoid using containers in favor of virtual machines

## Explanation

The CNCF Cloud Native Definition describes an approach that leverages containers, service meshes, microservices, immutable infrastructure, and declarative APIs to build systems that are loosely coupled, resilient, observable, and manageable.

## Explicação para criança

Cloud native é como construir com peças de Lego padronizadas em vez de esculpir uma peça única de madeira: fica mais fácil trocar, consertar e crescer aos poucos.
