# Question

Which two specifications together make up the Open Container Initiative's core standards?

## Options

- [x] The Image Specification and the Runtime Specification
- [ ] The Network Specification and the Storage Specification
- [ ] The Scheduling Specification and the Security Specification
- [ ] The Registry Specification and the Billing Specification

## Explanation

OCI defines the Image Specification (how an image's layers and config are packaged) and the Runtime Specification (how a compliant runtime must unpack and run that image as a container), forming the foundation container tools build on.

## Explicação para criança

São as duas regras principais: como embalar a caixa (imagem) e como abrir e usar essa caixa (runtime), para que caixas e abridores de fabricantes diferentes combinem.
