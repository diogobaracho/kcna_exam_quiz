# Question

What problem does container orchestration primarily solve?

## Options

- [x] Automating the deployment, scaling, networking, and healing of many containers across a fleet of machines
- [ ] Compiling application source code into containers
- [ ] Encrypting data at rest on a single machine
- [ ] Replacing the need for container images

## Explanation

Once you have more than a handful of containers spread across several hosts, manually starting, placing, networking, and restarting them does not scale; an orchestrator automates these operational tasks across the whole fleet.

## Explicação para criança

É como ter uma pessoa cuidando de centenas de brinquedos espalhados pela casa: sem um sistema de organização, fica impossível saber onde está cada um e consertar o que quebrar.
