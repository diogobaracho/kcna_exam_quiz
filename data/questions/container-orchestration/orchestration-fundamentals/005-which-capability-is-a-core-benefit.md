# Question

Which capability is a core benefit that orchestrators like Kubernetes provide over running containers manually with a plain container engine?

## Options

- [x] Automated scheduling, scaling, and failover across a cluster of machines
- [ ] Faster container image builds
- [ ] A replacement for the Linux kernel
- [ ] Automatic conversion of VMs into containers

## Explanation

A plain container engine like containerd can start and stop containers on one host; an orchestrator adds the cluster-wide layer that schedules workloads across many hosts, scales them up or down, and reacts to failures automatically.

## Explicação para criança

É a diferença entre ter um só forno em casa e uma padaria inteira com vários fornos, fornecedores e entregadores organizados para atender muita gente ao mesmo tempo.
