# Question

Kubernetes' design was strongly influenced by Google's internal cluster management systems. Which of these is one of them?

## Options

- [x] Borg
- [ ] Mesos
- [ ] Nomad
- [ ] Swarm

## Explanation

Kubernetes was created by Google engineers who applied lessons learned from Borg (and its successor Omega), Google's internal system for running large numbers of applications across shared clusters, though Kubernetes is an independent open-source rewrite.

## Explicação para criança

É como um projeto novo que aprende com uma versão mais antiga usada só dentro de uma empresa: o Kubernetes pegou boas ideias de um sistema interno do Google chamado Borg.
