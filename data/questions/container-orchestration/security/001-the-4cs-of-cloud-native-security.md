# Question

The '4Cs of Cloud Native Security' model describes security as layers around each other. Which four layers does it name?

## Options

- [x] Cloud, Cluster, Container, Code
- [ ] Compute, Cache, Cluster, Container
- [ ] Code, Compile, Compress, Cloud
- [ ] Cluster, Cache, Config, Code

## Explanation

The 4Cs model frames security in nested layers, from the outside in: Cloud (or Corporate datacenter), Cluster, Container, and Code, where each layer's security depends on the layers around it also being secured.

## Explicação para criança

É como bonecas russas: uma proteção fica dentro da outra - a nuvem por fora, depois o cluster, depois o contêiner, e por último o próprio código lá no centro.
