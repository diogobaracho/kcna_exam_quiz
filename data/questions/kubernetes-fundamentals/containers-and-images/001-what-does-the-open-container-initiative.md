# Question

What does the Open Container Initiative (OCI) define?

## Options

- [x] Vendor-neutral specifications for container image format and container runtime behavior
- [ ] The Kubernetes API schema
- [ ] A specific programming language for writing containers
- [ ] The networking rules used inside a service mesh

## Explanation

OCI publishes the Image Specification and the Runtime Specification, which describe how a container image is packaged and how a compliant runtime must run it, so tools from different vendors can interoperate.

## Explicação para criança

É como um manual de regras que todo mundo concorda em seguir para que caixas de brinquedos (imagens) feitas por fábricas diferentes encaixem no mesmo tipo de prateleira (runtime).
